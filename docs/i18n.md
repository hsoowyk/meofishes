# Translations

Languages: **English** (default), Português (Brasil), Français, Türkçe,
Deutsch, Español. Change it in **Settings → Language** (restart to apply).

The English text is the key. A language is a JSON file:

```json
{
  "code": "pt-BR",
  "name": "Português (Brasil)",
  "rtl": false,
  "strings": {
    "Liked songs": "Músicas que Gostei",
    "Added to queue: {track}": "Na fila: {track}"
  }
}
```

Keep the `{placeholders}`. Missing strings fall back to English.

- Built-in languages: `assets/locales/<code>.json`.
- Your own or fixes: `~/.local/share/meofishes/locales/<code>.json` (override
  the built-in strings; new codes add a language).

For developers: wrap interface strings in `tr("…")` (and `plural(n, "{n}
song", "{n} songs")`), then run

```sh
go run ./tools/i18nkeys                 # updates assets/locales/keys.json, prints what each language misses
go run ./tools/i18nkeys -missing fr     # lists the strings French lacks
```

Developer mode → Translations shows the coverage too.
